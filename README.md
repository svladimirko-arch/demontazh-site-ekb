## Заявки: настройка send.php
1. В блоке `CONFIG` укажите `email_to`, `email_from` (ящик на домене сайта).
2. Для Telegram: создайте бота у @BotFather → токен в `tg_token`; напишите боту, затем узнайте `chat_id` (например, через @userinfobot или `getUpdates`) → `tg_chat_id`.
3. Укажите `site_host` — ваш домен.
4. Нужен хостинг с PHP 7.4+ и расширением curl. Если PHP нет — заявки можно принимать только по телефону и в ВК.

Защита от спама: скрытое поле-ловушка, проверка времени заполнения, лимит 5 заявок/час с IP, проверка Origin, фильтр ссылок, очистка ввода.

## Публикация
- Любой хостинг с PHP, включить HTTPS (бесплатный Let's Encrypt) и редирект http→https.
- Для рекламы: подключить Яндекс.Метрику, цели `call_*`, `vk_*`, `form_sent` уже отправляются из кода (нужно вписать `YM_ID`).
- QR-код: ссылка с UTM, например `https://ваш-домен/?utm_source=flyer&utm_medium=qr`.
- Проверка: PageSpeed Insights, мобильная версия, отправка тестовой заявки.
